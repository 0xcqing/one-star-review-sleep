A deadpan one-star review of an everyday essential: sleep.

> Sleep: eight hours promised, four delivered, the rest spent rewriting an email I already sent.

One line, at most 160 characters, for the make.fun bounty "One-star review of
something essential." The grievance: sleep under-delivers, and the shortfall
gets spent rewriting an email already sent.

## Run

```sh
node main.ts
```

Writes the review plus a trailing newline to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output`), creating the directory if needed. No dependencies, no network.
